# docs/archive

This directory holds historical development tracking documents that are not
part of the current operator runbook or architecture canon.

Files here are **excluded from release artifacts** and are retained only for
development history reference.

| File | Content |
|------|---------|
| `phoenix_backlog.csv` | Development backlog tracker (PHX-SEC-NNN issues) used during the v9 implementation phase. Closed items are reflected in git commits. |
